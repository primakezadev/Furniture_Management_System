# Online Furniture Information Management System

A PHP and MySQL web application for managing furniture information, customers, shopping carts, and customer orders. The system supports two main user roles: **Admin** and **Customer**.

## Project Overview

This project was developed for the Backend Development Using PHP module (ITLDP601), Group VI.

### Main Features

#### Admin
- Log in and log out securely.
- Change account password.
- Register furniture, including furniture details, price, quantity, and an image.
- View, update, and delete furniture records.
- View, update, and delete customer records.
- Receive and manage customer orders.

#### Customer
- Register an account, log in, and log out.
- Change account password.
- Browse and search available furniture.
- View furniture details and images.
- Add furniture to a shopping cart and view the cart.
- Place furniture orders.

#### General
- PHP backend with a MySQL database.
- Password storage using PHP `password_hash()` and password verification using `password_verify()`.
- Pagination for listing records.
- Composer dependency management.
- PHPMailer integration for email-related functionality.

## Requirements

Before running the project, install:

1. XAMPP with Apache, MySQL, and PHP.
2. Composer.
3. A modern web browser.

## Installation and Setup

### 1. Clone the repository

Open PowerShell or Command Prompt and run:

```bash
git clone https://github.com/primakezadev/Furniture_Management_System.git
```

### 2. Move the project into the XAMPP web directory

Place the project folder inside:

```text
C:\xampp\htdocs\
```

For the current local development setup, the project may be located at:

```text
C:\xamp_new\htdocs\Furniture_Management_System
```

### 3. Start Apache and MySQL

1. Open the XAMPP Control Panel.
2. Start **Apache**.
3. Start **MySQL**.

### 4. Create and import the database

1. Open `http://localhost/phpmyadmin` in your browser.
2. Create a database named:

```text
furniture_management
```

3. Open the project's `database/` folder.
4. Import the provided SQL file into the `furniture_management` database using phpMyAdmin.

The imported database should create the tables required by the application.

### 5. Configure the database connection

Open:

```text
config/database.php
```

Check that the connection settings match your local MySQL configuration. The local development defaults are:

```php
$host = "localhost";
$dbname = "furniture_management";
$username = "root";
$password = "";
```

If your MySQL username or password is different, update the values in the configuration file. Keep database credentials private and do not commit production credentials to GitHub.

### 6. Install PHP dependencies

From the project root, run:

```bash
composer install
```

This installs the dependencies listed in `composer.lock`, including PHPMailer, and creates the `vendor/` directory if it is not present.

### 7. Configure email functionality (if required)

Email features use PHPMailer. Configure the SMTP host, port, username, password, and sender details in the relevant project configuration. Use an email app password or other provider-approved SMTP credentials where required. Do not publish SMTP credentials in the repository.

### 8. Run the application

Open the following address in your browser:

```text
http://localhost/Furniture_Management_System/
```

If your XAMPP installation uses a different web-root folder, use the matching local URL.

## Account Access

The application has two roles:

- **Admin:** uses an administrator account.
- **Customer:** can create an account through the registration page.

No default administrator username or password is documented in this README. Use the administrator account configured for your project or create one using the project's database setup instructions. For security, do not publish real passwords in a public repository.

## Security Notes

- Passwords should be stored as hashes using `password_hash()`, not as plain text.
- Use `password_verify()` when checking a submitted password.
- Use prepared statements for database queries.
- Validate and sanitize user input.
- Validate uploaded image types and sizes.
- Keep database and SMTP credentials out of public source control.
- Use HTTPS and secure configuration when deploying the application.

## Deployment

The application can be deployed to a PHP-compatible web hosting service with a MySQL database.

For deployment:

1. Upload the PHP project files to the hosting service.
2. Create a production MySQL database and import the project's SQL script.
3. Update the database connection settings for the production database.
4. Configure SMTP settings if email functionality is enabled.
5. Ensure the `uploads/` directory is writable by the application where image uploads are used.
6. Configure the hosting service to serve the project through its public web directory.
7. Test administrator and customer workflows after deployment.
